# 공휴일과 운행일 계산

## 공휴일 자료

인증키 없이 공개 JSON을 제공하는 [hyunbinseo/holidays-kr](https://github.com/hyunbinseo/holidays-kr)를 사용합니다. 우주항공청 월력요항을 가공한 커뮤니티 자료이며 정부 API 자체는 아닙니다. [MIT 라이선스](holidays-kr-LICENSE.txt)를 함께 보관합니다.

- 원본: `https://raw.githubusercontent.com/hyunbinseo/holidays-kr/main/public/<연도>.json`
- 공용 API: `GET /api/holidays?year=2026`
- 응답: `{ year, holidays: { "2026-10-05": ["대체공휴일(개천절)"] }, source: "holidays-kr", fallback: false }`
- 서버는 6시간 캐시합니다. 웹·Flutter는 현재 연도와 다음 연도를 조회하고 6시간 동안 재사용합니다. 캐시가 연속 적용되면 변경 반영까지 약 12시간 걸릴 수 있습니다. 오류 후 재시도 간격은 5분입니다.
- 날짜 형식·연도·명칭 배열·최소 항목·연초/연말 공휴일을 검증한 뒤 적용합니다. 이는 형식과 명백한 누락 검증이며, 모든 공휴일의 법적 정확성을 보장하는 검사는 아닙니다.
- 서버 원본 조회 실패 시 배포에 포함된 자료를 `fallback: true`로 반환합니다. 해당 연도도 없으면 503입니다.
- 클라이언트는 정상 응답을 기기에 저장하고, 실패하면 마지막 정상 자료 또는 내장 자료를 유지합니다. 서버가 내장 사본을 반환할 때는 더 최신일 수 있는 기존 기기 캐시를 덮어쓰지 않습니다. 현재 내장 범위는 2025~2027년입니다.
- 알 수 없는 연도는 평일로 단정하지 않습니다. ‘공휴일 정보 확인 필요’를 표시하고 요일 구분이 없는 공통 시간표만 계산합니다.
- 제공처의 임시공휴일 반영이 늦어질 수 있습니다. 운영자는 공휴일 변경 공지가 있을 때 원본과 `/api/holidays`를 확인합니다.

Nager.Date v3는 일부 원래 공휴일을 대체 날짜로 치환하고, 조사한 한국 공급자 구현에는 2027년 기독탄신일 대체공휴일 등 누락이 있어 채택하지 않았습니다. 정부 특일 API는 인증키가 필요하므로 현재 연결하지 않습니다.

내장 사본을 갱신하려면 다음을 실행합니다. 전체 다운로드와 검증이 끝난 뒤 웹·앱 양쪽 파일을 씁니다. 다음 연도 자료가 아직 발표되지 않았다면 해당 연도만 생략합니다.

```sh
pnpm holidays:sync
```

## 운행일 규칙

- 모든 계산은 기기 시간대와 무관하게 한국 시간(UTC+9)을 사용합니다.
- 공휴일은 `공휴일`, `휴일`, `공통`에 해당합니다. 평일·토요일 시간표를 동시에 선택하지 않습니다.
- 일반 토요일은 `토요일`, `휴일`, `공통`, 일요일은 `일요일`, `휴일`, `공통`입니다.
- 파일명 운행일 **및** 행의 구분을 모두 만족해야 합니다. 쉼표 공백과 `토`, `일` 축약형을 처리합니다.
- `토, 일, 공휴일 미운행`, `일,공휴일 미운행(41-2 대체)`, `토요일 운행안함`, `평일만 운행` 같은 명시적 비고 제한을 적용합니다. `국형사 미운행`처럼 특정 지점만 제외하는 비고로 전체 노선을 취소하지 않습니다.
- 방학은 학교마다 다르고 공식 노선별 적용 기간이 구조화되어 있지 않아 자동 추정하지 않습니다. 기본 계산은 학기 중 기준이며 방학 시간표와 통학 관련 비고를 함께 확인해야 합니다.
- 출발지 변경, 경유지 변경, 특정 요일의 통학 출발 같은 자유 형식 비고는 출발 카드와 상세 화면에 그대로 표시합니다. 임의로 다른 종점의 시각을 만들어내지 않습니다.

## 다음 출발

각 시간표에 대해 오늘과 내일의 운행일을 각각 판별합니다. 오늘 지난 시각을 무조건 내일로 바꾸지 않습니다. 내일까지 출발이 없으면 다음 출발 목록에서 제외하고 전체 노선 시간표에서 확인하도록 안내합니다.

`H:mm` 또는 `HH:mm` 형식이며 00:00~23:59인 시각만 계산합니다. `-`, `순환`, `통학12` 등의 원본 표시는 상세 화면에 남기되 카운트다운에서는 제외합니다. 출발 시각을 1초라도 지났으면 다음 출발에서 제외하며 남은 분은 올림합니다. 정렬은 날짜를 포함한 실제 대기 시간 순입니다.

`arrivalTime`은 반대 종점의 출발 시각입니다. 두 시각의 차이를 소요 시간으로 표시하지 않으며 실시간 ‘운행 중’으로 추정하지 않습니다. 상세 화면은 5분 이내 예정 출발, 출발 시각 지남, 오늘 미운행을 구분합니다.

조회 캐시는 5분 후 재조회하며 동시 요청을 합칩니다. 운행일 여부는 캐시에 고정하지 않고 다시 계산합니다. 웹·앱의 종점 상세 화면은 매분 갱신합니다. 종점 노선 수는 운행 횟수나 요일별 시간표 수가 아닌 고유 버스 번호 수입니다.

## 회귀 검증

`pnpm test:logic`, `flutter test`에서 임시공휴일·선거일·대체공휴일, 해외 시간대, 자정·연말, 금요일에서 토요일 공휴일 전환, 일요일에서 월요일 대체공휴일 전환, 비고 미운행, 잘못된 시각, 반대 종점, 깨진 캐시, API 실패를 검증합니다. 크롤러 테스트는 구분 열이 없는 표에서도 시각을 요일로 잘못 읽지 않는지 확인합니다.
