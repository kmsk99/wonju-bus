# 이전 React Native 구현

Flutter를 현재 Android 앱으로 사용하면서 보존한 이전 구현입니다. 원래 `apps/mobile`에 있었으며 Git 이력을 유지해 이동했습니다.

이 디렉터리는 pnpm workspace, CI, Vercel 배포 및 Neon 데이터 동기화 대상에서 제외합니다. 내부 JSON과 빌드 설정은 당시 구현의 참고 자료이며 현재 시간표나 실행 가능성을 보장하지 않습니다. 현재 앱 개발은 `../../apps/flutter`에서 진행하세요.

필요하면 별도 환경에서 의존성과 Android 도구를 복원해 조사합니다. 이 보관본을 운영 APK로 배포하지 않습니다.
