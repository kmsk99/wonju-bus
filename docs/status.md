# 현재 지원 범위

2026-10-04 기준입니다. 운영 배포와 릴리스 버전은 GitHub Actions, Vercel 배포 기록, GitHub Releases에서 확인합니다.

## 제공 중

- 종점·노선 검색 및 상세 시간표
- 한국 시간 기준 오늘·내일의 유효한 출발과 남은 시간 표시
- 공개 공휴일 JSON 연동, 대체·임시공휴일 처리, 정상 캐시·내장 자료 대체
- 요일별 파일·행 구분·명시적 비고의 미운행 제한 적용
- Vercel Marketplace Neon Free를 통한 웹·Flutter 공용 데이터
- 주간 수집, 세션 처리, 재시도, 부분 수집 차단, 변경 감지
- Flutter의 정상 캐시·내장 시간표 대체
- 홈페이지 APK 다운로드와 전용 키 서명
- CI의 웹 lint·빌드, 크롤러 회귀 검사, 데이터·버전 정합성, Flutter 분석·테스트

## 제약과 후속 과제

- 실시간 차량 위치나 실제 도착 예측은 제공하지 않습니다.
- 방학 기간은 학교·노선별 공식 기간이 없어 자동 판별하지 않습니다. 통학 출발지 변경 등 자유 형식 비고는 원문을 확인해야 합니다.
- 공휴일 공개 자료의 변경 반영이 늦거나 장기 오프라인이면 최신 임시공휴일을 놓칠 수 있습니다. [공휴일과 운행일 계산](calendar-and-service.md)을 참고하세요.
- 웹은 서비스 워커 기반 완전 오프라인 PWA가 아닙니다.
- iOS/Play Store 배포는 하지 않았습니다. Android는 APK 직접 설치 방식입니다.
- 원주시 ITS 연결이 GitHub 실행 환경에서 간헐적으로 시간 초과됩니다. 재시도가 모두 실패하면 해당 주의 갱신은 이루어지지 않고 기존 시간표를 유지합니다. `ITS 연결 진단` 워크플로로 연결을 확인할 수 있습니다.
- 원주시 ITS의 HTML 구조나 접근 정책이 바뀌면 크롤러를 수정해야 합니다.
- DB의 과거 전체 snapshot 보관·복구 UI는 없습니다. 최근 정상 실행 60건은 변경 여부·건수 등 메타데이터입니다.

기존 개발 계획에 남아 있던 완료/미완료 체크리스트는 이 문서로 대체합니다. 구현되지 않은 기능을 제공 중이라고 기재하지 않습니다.
